## 三、核心结论的推理链（学这个结构，不学结论）

**激活标准**：复用官方口径「连续 6 周活跃 = 种子用户」→ 定义为周活跃激活租户数（WAAT）。

**漏斗**：触达 → 注册 → 首次登录（13%）→ **完成建档（5.8%，−55%）** → 激活（−41%）。

**关键读法**：建档之后到激活几乎不再流失 → **问题高度集中在入口，产品本身能留人**。这一判断决定了方案重心（修入口，而非改产品价值）。

**多维下钻**：行为分层（只登录未建档 / 建档中止 / 建档完成无后续）× 来源分层（广告 / 生态 / 裂变 / 地推）× 定性（社区原声里大量「找不到入口」「要填的太多」）。

**结论句**：
> 以个人身份试用的中小企业老板/主管（尤其加工型、贸易型），在「基础数据初始化」与「团队协作搭建」两个环节流失，因『先建档才见价值』的路径设计 + 『缺少跨角色推力』+ 『缺少过渡式引导』三者叠加。

**根因表**：R1 协作无推力 / R2 建档门槛与引导不闭环 / R3 模板覆盖面窄 / R4 登录与可用性摩擦 / R5 付费触发时机缺失。

## 四、最有价值的一幕：证据推翻假设

**初版根因（P0）**：「协作价值被锁在付费墙后——免费版 1 账号，个人版不支持子账号。」
依据：帮助中心文档推测（当时登录被滑块验证拦住，未能实测）。

**实机证据（用户补交 19 张截图后）**：人事管理模块明确具备「一键同步子账号 / 设置权限 / IP 白名单（启用·禁用）」；员工列表已自动生成主账号条目，但**部门数 0、岗位数 0**。

**结论改写**：
> **不是「锁」，是「没导」**——协作能力完全开放，但产品不会主动要求你把同事拉进来。用户以个人身份注册后看到的是「0 部门 0 岗位」的空组织架构，不会自发去走「建部门 → 加员工 → 设岗位」这套 HR 流程。ERP 的价值必须跨角色才显现，而跨角色这一步没有任何推力。

**处理方式**：不隐藏修正痕迹，把它写成报告里的能力证明（「用实测证据修正自己的假设」）。

> 这个案例正是 `08-screenshot-request-and-review.md` 闸门一的由来：当时若在登录被拦时先索要截图、拿到后再动笔，这一轮返工本可避免。

同批修正还有 4 处：引导密度其实不低（真问题是「讲功能不讲任务闭环」）、降门槛抓手（AI 一键初始化 / 三步导入）只出现在二级页（判定为运营触达问题而非产品缺失）、生态协同页工具全标「未来规划/未上线」（亮点已降调）、顶栏「有效期至 2026-09-24」但到期不降级（缺付费紧迫感）。

## 五、JD 对标的具体做法

把 JD 五条职责做成覆盖度矩阵：

| JD 职责 | 原覆盖状态 | 补齐动作 |
|---|---|---|
| 线索与获客运营 | 只有渠道清单 | 补 3.4 表 2「渠道追踪与 ROI 评估表」 |
| 试用激活运营 | 已覆盖 | 再补表 1「试用分层 × 运营策略矩阵」 |
| 付费转化与生命周期 | 优先级偏低 | 根因上调至 P1 + 表 3 付费/续费环节 |
| 内容与品牌运营 | 仅提 5A | 补表 4「内容资产清单」 |
| 数据复盘与跨部门协同 | 缺核心交付物 | 补全流程策略查表 + 线索评分分层 + 6 份 SOP |

补完后新增附录 B「岗位能力对标自查」，做成最后一页：JD 职责 → 报告章节落点 → 自评，并附一段「本报告坚持的三件事」（用实测修正假设 / 不编造数据 / 建议必须可验收）。

## 六、踩坑清单（直接复用结论）

| 坑 | 现象 | 解法 |
|---|---|---|
| 滑块验证拦住登录 | `agent-browser drag` 无法通过阿里云滑块 | **触发闸门一**：不绕过；截图取证写成登录摩擦点，随后输出截图索取清单**停下来等截图**。❌ 不要「声明未实测后继续写报告」——那是 1.1.0 前的旧做法 |
| 登录按钮点不动 | 普通 click 无效 | 用 `agent-browser find text "登录" click` |
| 对比度审计假告警 | 33 处告警中 24 处是渐变背景误报 | 审计脚本跳过带 `background-image` 的元素 |
| 漏斗注释被裁 | SVG 内注释超出 viewBox 被静默裁掉 | 图注移到 HTML 层（`.figcap` / `.note.dim`） |
| 断崖标注压图 | 标注框盖住图形 | 标注移到图形左侧 + 引导线 |
| 白字对比度不足 | 阶段卡第三张渐变末端 `#4FC3F7` 太白 | 换 `#1668DE`，白字达 AA |
| 大文件手改错配 | 直接编辑易静默替换错位置 | 用补丁脚本 + `assert s.count(old)==1` + 先备份 `.bak` |
| 手写 base64 | 又慢又易错 | 用 `scripts/build_single_file.py` |

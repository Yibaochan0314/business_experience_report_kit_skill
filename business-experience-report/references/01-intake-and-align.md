# 01 · 输入采集与口径对齐

## 一、输入登记表

开工前把这张表填满。左栏是用户给的，右栏是你检索的，右栏每一项都必须带 URL。

| 字段 | 内容 | 来源 |
|---|---|---|

| 体检目的（要回答的问题） | 例：为什么试用激活率偏低 | 用户 |

| 账号可用性 | 有账号可登录 / 有账号但登录受阻（需索取截图）/ 只有截图 / 都没有 | 用户 |

## 二、口径对齐（动笔前必须确认的 4 件事）

用提问的方式对齐，不要自己替用户决定。

1. **报告定位**——「这份报告主要给谁看？」
   - 求职作品集 → 重专业呈现、结构化方法论、可分享；结论要能被面试官追问
   - 内部汇报 → 需贴真实数据、可落地执行路径、明确责任部门
   - 方法论演练 → 数据可为推演，重在逻辑闭环完整

2. **数据口径**——「你能提供的材料到什么程度？」
   - 有账号且能登录 → 实机体验，实测结论优先
   - **有账号但登录受阻**（验证码 / 风控 / 权限不足）→ **请用户本人登录后提供截图**（流程见 `08-screenshot-request-and-review.md`），不要自行降级继续
   - 只有截图 → 按截图还原路径，结论标注「依据用户提供的截图」
   - 仅公开信息 → 所有内部指标标注为推演并说明依据；提前告知用户：报告缺少实测支撑，根因需实测校准
   - 有部分真实数据 → 用真值替换推演，并注明「实测值」

3. **视觉参考**——「视觉上有参考图吗？」
   - 有 → 解析设计令牌后复述确认
   - 无 → 用 `06-visual-system.md` 默认基线

4. **待补材料**——把缺的东西列成清单，明确「不补会有什么影响」

## 三、截图采集规范

**命名按证据用途，不按页面顺序。** 这样你在写作时能直接按论点取图。

```
shots/
├── w01-home-guide.jpg        # 官网 / 工作台首页引导
├── w02-empty-state.jpg       # 空状态（0 条数据）
├── w05-hr-subaccount.jpg     # 人事管理的子账号能力
├── w13-eco-notice.jpg        # 生态协同「未上线」提示
└── embed-*.jpg               # 压缩后用于内联的版本
```

命名前缀建议：`w` = 登录后工作台，`o` = 官网公开页，`qa` = 评审用截图。

**压缩规则**（图片太大报告打不开）：
```bash
# 内联用：宽度 1000px、JPEG 质量 72，通常能把 1.5MB 压到 150KB 级别
sips -s format jpeg -s formatOptions 72 --resampleWidth 1000 src.png --out shots/w01-home-guide.jpg
```
控制总量：**内联图片总大小建议 ≤ 3MB**。超过则降低 `formatOptions` 或 `resampleWidth`，或减少嵌入张数（优先保「能推翻结论」的那几张）。

## 四、材料清点检查表

写作前逐项打勾，缺项要显式告知用户影响：

- [ ] 官网首页原文（含产品定位与关键数字）
- [ ] 定价页原文（版本、价格、试用规则、抵扣规则）
- [ ] 帮助中心目录（模块清单的最可靠来源）
- [ ] 上手/实施类文档（激活路径的关键证据）
- [ ] 公司背景与财务数据
- [ ] 行业数据（规模、渗透率）
- [ ] 用户真实评价（≥5 条，带出处）
- [ ] **登录可行性已确认**（三选一：可登录实测 / 已索取截图并拿到 / 用户明确表示无法提供）
- [ ] 实机截图（能覆盖「注册 → 登录 → 核心功能 → 付费入口」关键节点）
- [ ] 视觉参考图或确认使用默认基线

## 五、成本预估

一份合格报告的工作量分布（用于判断是否要降级范围）：

| 阶段 | 工作量占比 | 可压缩性 |
|---|---|---|
| 取证（检索 + 实机） | 30% | 低——证据不足报告就空 |
| 诊断与解法撰写 | 35% | 低——这是报告的价值本体 |
| HTML 建档（含图示） | 25% | 中——可减少图示数量 |
| 视觉评审与导出 | 10% | 低——不能跳，跳了观感崩 |

若用户材料严重不足，**优先砍「图示数量」而不是「取证深度」**。少两张图报告依然成立，证据不足报告就不成立。

**排期提醒**：若触发闸门一（登录受阻需索取截图），取证阶段会多出一个等待往返。要在开始时就把这一轮预留出来，**不要因为等待而压缩诊断深度**——那正是闸门要保护的东西。
